Apertus on your own computer

The hosted demo works on phones and computers without a model download. Its public questions go to Public AI through Cloudflare. It has a finite free allowance; the demo is not Swiss-sovereign hosting.

Keep inference on your Mac

The optional local version runs Apertus v1.5 8B on Apple Silicon. It was tested on an M3 Pro with 18 GiB memory. Allow at least 8 GiB free disk space; the model download is about 4.6 GB. Other hardware is not yet verified.

Install Python 3.11 or newer and Git, then run these commands in Terminal:

git clone --branch codex/local-apertus-gate0-evidence https://github.com/Devpen787/stimmfolgen.git
cd stimmfolgen
make local-download
make local-run

Open http://127.0.0.1:8770. Setup downloads the runtime, pinned model and official source. Inference then runs locally with no API key. Ctrl+C stops the services started by this command. The app and model bind only to your own computer.

Already have the model? Use make local-setup to install the runtime without downloading weights. See the repository for custom paths and ports. This packaging is experimental; local launcher proof uses an existing pinned model, and fresh-install verification is reported separately.

Your choices and notes

Tracking is visit-only by default. An optional passphrase encrypts saved votes and notes in this browser. There is no account or cross-device sync. Losing the passphrase can mean losing the saved data. Neither the hosted nor local model receives your saved choices or notes.

What is covered

Live answers cover five reviewed historical AHV statements, using the evidence available before the March 2024 vote. Apertus matches your question to reviewed statements; the app displays their accepted wording and sources unchanged. The question match is not human reviewed. Earlier local failures included aggregate costs for a personal-cost question. Fictional teaching examples improved that result, but the current 4-bit matcher still selects unrelated context or matches another proposal. Use the reviewed explanation and inspect the sources. Local live matching is experimental. Other catalogue votes have official references but no reviewed AI explanation yet.
