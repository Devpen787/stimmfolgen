Apertus on your own computer

The online demo works on phones and computers without a model download. To keep questions on your own computer, you can install the local version.

What you need

An Apple Silicon Mac, Python 3.11 or newer, Git and Docker Desktop. The model is about 4.6 GB; allow at least 12 GB free space. Testing uses an M3 Pro with 18 GB memory. Other hardware is not verified.

Install and open

git clone --branch codex/local-apertus-gate0-evidence https://github.com/Devpen787/stimmfolgen.git
cd stimmfolgen
make local-download
make run ONPREM=1

Open http://127.0.0.1:8770. Setup needs internet access for software, model and source downloads. After setup, questions go to Apertus on this Mac. The app runs in Docker. No hosted AI account or API key is needed.

Already have the pinned model? Use make onprem-setup MODEL_DIR=/path/to/model, then make run ONPREM=1 MODEL_DIR=/path/to/model. Stop with Ctrl+C. These commands leave unrelated services alone.

Your choices and notes

Tracking stays in the current visit unless you choose to save an encrypted vault. Keep your passphrase safe: there is no account, recovery service or cross-device sync. Saved votes and notes are never attached to an Apertus question.

What to expect

Answers are limited to the official sources included in the app. AI can miss information or misunderstand a question; inspect the linked source. The local and online versions use different model formats and can give different matches. Neither version recommends how to vote or calculates a definite personal tax bill.
