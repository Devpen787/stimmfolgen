## Reproduce

From the repository root, with a compatible Mac runtime and the recorded pinned weights already installed:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install pymupdf==1.28.2
.venv/bin/python track_2b/src/gate0/source_probe.py --out .local/gate0/source.json --pdf-out .local/gate0/booklet.pdf --spans-out .local/gate0/spans.json
# In a separate terminal, use your existing MLX runtime:
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 HF_HUB_DISABLE_TELEMETRY=1 python -m mlx_lm server --model .local/models/apertus-v1.5-8b-mlx-4bit --host 127.0.0.1 --port 8766 --temp 0 --max-tokens 1400 --chat-template-args '{"enable_thinking":false}' --decode-concurrency 1 --prompt-concurrency 1 --prompt-cache-size 1 --prefill-step-size 512
.venv/bin/python track_2b/src/gate0/local_model.py --model-dir .local/models/apertus-v1.5-8b-mlx-4bit --base-url http://127.0.0.1:8766/v1 --out .local/gate0/identity.json
.venv/bin/python track_2b/src/gate0/span_probe.py --source-report .local/gate0/source.json --source-pdf .local/gate0/booklet.pdf --local-model-report .local/gate0/identity.json --out-dir .local/gate0/new-run
# Expected diagnostic exit 2 when a bounded trial fails; preserve the output.
.venv/bin/python -m unittest discover -s track_2b/tests -p 'test_gate0*.py' -v
.venv/bin/python track_2b/src/gate0/verify_span_evidence.py --evidence-dir track_2b/docs/evidence/gate0-spans-2026-10-12 --source-pdf .local/gate0/booklet.pdf
```

The cloud source workflow runs deterministic checks without credentials or a model. The manual inference workflow requires a self-hosted Mac labelled `apertus` with an existing loopback MLX server; no runner was set up or workflow dispatched in this run.
